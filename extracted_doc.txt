Project Brief ของ GRURU MUSEUM ภายใต้ธีม “New Knowledge. New Storytelling. Built for Everyday Living.” แบ่งเป็น 11 ขั้น เริ่มจากแนวคิดหลักและจบที่การส่งต่อให้ Google Antigravity สร้างเว็บ 
ขั้นที่ 1 กำหนดแก่นของโปรเจกต์ 
(1. Project Overview) 
GRURU MUSEUM คือแบรนด์พิพิธภัณฑ์ความรู้ดิจิทัลที่นำเสนอผลงานจากการสร้างสรรค์ความรู้ แบรนด์เชื่อว่า “ความรู้ที่ซ่อนอยู่ในอดีต” ยังมีคุณค่ากับชีวิตวันนี้ เพียงแต่ต้องถูกขุดค้น ถอดรหัส และเล่าใหม่ คอนเซปต์ของเว็บคือ Future Archaeology หรือ “ห้องแล็บของนักโบราณคดีจากอนาคต” ที่ย้อนมาศึกษาความรู้ของมนุษย์เหมือนศึกษาวัตถุโบราณ บรรยากาศจึงเป็นการปะทะกันของสองขั้ว คือความนิ่งเรียบแบบแกลเลอรี modern art กับความล้ำแบบห้องแล็บ sci-fi โปรเจกต์นี้ครอบคลุมการพัฒนาและเปิดตัวชุดข้อมูลกราฟความรู้ (Knowledge Graph) สองรูปแบบ แบบแรกคือ Data Booming เป็นประสบการณ์แบบนำทาง ผู้ใช้เริ่มจากหัวข้อเดียวแล้วหัวข้อนั้น “ระเบิด” ออกเป็นความรู้ที่เชื่อมโยงกันทีละชั้น แบบที่สองคือ Interactive Graph เป็นแผนที่ความรู้ฉบับเต็มที่ผู้ใช้สำรวจ กรอง และเจาะลึกได้เอง (ความหมายของ Data Booming ตรงนี้เป็นการตีความของผม ถ้าคุณตั้งใจไว้ต่างออกไป แก้เฉพาะส่วนนี้ได้โดยไม่กระทบส่วนอื่น) ทุกเนื้อหาต้องตอบธีมให้ครบสามคำ New Knowledge คือความรู้ที่ค้นพบใหม่และตรวจสอบที่มาได้ New Storytelling คือเล่าด้วยภาพ กราฟ และการโต้ตอบแทนบทความยาว ส่วน Built for Everyday Living คือทุกเรื่องต้องจบด้วยสิ่งที่นำไปใช้ได้จริง
ขั้นที่ 2 เขียนวิสัยทัศน์และพันธกิจ
 (1.1) วิสัยทัศน์คือ “เป็นพิพิธภัณฑ์ความรู้ดิจิทัลที่ปลุกความรู้ซึ่งซ่อนอยู่ในอดีตให้กลับมามีชีวิต ในรูปแบบเรื่องเล่าใหม่ที่คนรุ่นใหม่ใช้ได้จริงทุกวัน” ฉบับภาษาอังกฤษสำหรับหน้าเว็บคือ “Reviving hidden knowledge from the past as new stories, built for everyday living.” พันธกิจมีห้าข้อ เรียงตามเส้นทางของความรู้ ข้อหนึ่ง Excavate คือขุดค้นและคัดสรรความรู้จากประวัติศาสตร์ วิทยาศาสตร์ และภูมิปัญญา โดยระบุแหล่งที่มาทุกชิ้น ข้อสอง Decode คือถอดรหัสข้อมูลให้เป็นโหนดและความสัมพันธ์ในกราฟความรู้ ข้อสาม Retell คือเล่าใหม่ผ่านนิทรรศการดิจิทัลแบบ visual storytelling ที่ดูจบได้ในไม่กี่นาที ข้อสี่ Connect คือเปิดชุดข้อมูลผ่าน Data Booming และ Interactive Graph ให้เห็นว่าความรู้ข้ามยุคสมัยเชื่อมกันอย่างไร ข้อห้า Apply คือปิดท้ายทุกนิทรรศการด้วยการ์ด Everyday Takeaway ที่บอกวิธีใช้ในชีวิตประจำวัน ห้าคำนี้ใช้เป็นโครงเรื่องมาตรฐานของทุกหน้านิทรรศการได้ด้วย
ขั้นที่ 3 วางตำแหน่งแบรนด์
 (1.1 Brand Positioning) ประโยคหลักคือ “สำหรับคนวัย 22–40 ปีที่อยากเข้าใจโลกให้ลึกกว่าคลิปสั้น แต่ไม่อยากรู้สึกเหมือนนั่งเรียน GRURU MUSEUM คือพิพิธภัณฑ์ความรู้ดิจิทัลสไตล์ modern art ผสม sci-fi ที่เปลี่ยนความรู้จากอดีตให้เป็นกราฟที่สำรวจได้ด้วยตัวเองและเป็นเรื่องเล่าที่ใช้ได้จริง ต่างจากสารานุกรมออนไลน์ที่แห้งและคอนเทนต์สั้นที่ไม่บอกที่มา เพราะทุกเรื่องเชื่อมกันเป็นเครือข่ายข้อมูลที่ตรวจสอบได้ และนำเสนอด้วยภาษาภาพที่จำได้ทันที” ถ้าวาดเป็น Perceptual Map ให้แกนนอนคือ “วิชาการ ↔ สนุก” และแกนตั้งคือ “เล่าแบบเส้นตรง ↔ เชื่อมแบบเครือข่าย” GRURU ต้องยืนในมุมที่ “สนุกแต่มีหลักฐาน” และ “เป็นเครือข่ายที่โต้ตอบได้” แก่นแบรนด์สรุปได้ในประโยคเดียวว่า “อดีตคือข้อมูล อนาคตคือเรื่องเล่า” บุคลิกแบรนด์คือ “ภัณฑารักษ์จากอนาคต” ที่ฉลาดแต่ไม่เก๊ก ขี้เล่นแต่มีหลักฐานเสมอ ส่วนคำสัญญาของแบรนด์คือทุกการเยี่ยมชมต้องได้อย่างน้อยหนึ่งเรื่องกลับไปใช้จริง
ขั้นที่ 4 เจาะกลุ่มเป้าหมาย 
(1.2) กลุ่มหลักอายุ 22–40 ปี แบ่งเป็นสามบุคลิกเพื่อให้ออกแบบได้ตรงจุด บุคลิกแรกคือ Curious Starter อายุ 22–27 ปี เป็นนักศึกษาจบใหม่หรือ first jobber ที่ใช้มือถือเป็นหลักและชอบของสวยที่แชร์ต่อได้ กลุ่มนี้ต้องการเรื่องที่ดูจบใน 3–5 นาที และการ์ดความรู้ขนาด 1080×1350 px สำหรับโพสต์โซเชียล บุคลิกที่สองคือ Creative Professional อายุ 25–34 ปี เช่น นักออกแบบ นักการตลาด ครีเอเตอร์ และนักพัฒนา ที่หาแรงบันดาลใจและข้อมูลอ้างอิง กลุ่มนี้ต้องการ Interactive Graph แบบเจาะลึก ระบบบันทึกคอลเลกชัน และชุดข้อมูลที่ดาวน์โหลดไปต่อยอดได้ บุคลิกที่สามคือ Lifelong Learner อายุ 30–40 ปี เป็นคนทำงานหรือพ่อแม่รุ่นใหม่ที่อยากรู้ที่มาของสิ่งรอบตัว เช่น อาหาร สุขภาพ และภูมิปัญญา กลุ่มนี้ต้องการความน่าเชื่อถือ ตัวอักษรที่อ่านสบาย และ Everyday Takeaway ที่ชัดเจน insight ร่วมของทั้งสามกลุ่มคือ “อยากรู้ลึก แต่ไม่อยากรู้สึกว่ากำลังเรียน” ดังนั้นเว็บต้องออกแบบแบบ mobile-first ใช้โหมดมืดเป็นค่าเริ่มต้น และเปิดดูแหล่งอ้างอิงได้ในคลิกเดียว
ขั้นที่ 5 วางชุดสีหลัก 
(2.1) แนวคิดคือ “Past Warm × Future Electric” สีอุ่นแทนอดีต สีไฟฟ้าแทนอนาคต แล้วให้สองขั้วนี้ตัดกันบนพื้นดำแบบห้องแล็บ สีพื้นฐานมีห้าสี Void Black #0B0B0F เป็นพื้นหลังหลักของโหมดมืด Lab Graphite #17171F ใช้กับพื้นการ์ดและพาเนล Grid Line #2C2C3A ใช้กับเส้นขอบ เส้นตาราง และตัวแบ่ง Muted Fog #8A8A9E ใช้กับข้อความรองและคำอธิบาย และ Archive Paper #F2EDE3 เป็นสีขาวนวลแบบกระดาษเก่า ใช้เป็นสีตัวอักษรหลักบนพื้นดำและเป็นพื้นหลังของโหมดสว่าง สีแบรนด์มีสี่สี Specimen Lime #D7FF3A เป็นสีเอกลักษณ์อันดับหนึ่ง ใช้กับปุ่ม CTA โหนดที่ถูกเลือก และไฮไลต์ ตัวอักษรบนพื้นสีนี้ต้องเป็นสีดำเสมอ Ember Orange #FF5A1F เป็นสีของ “อดีต” ใช้กับป้ายยุคสมัยและเงาแข็งของปุ่ม Quantum Violet #8C6BFF เป็นสีของ “เทคโนโลยีและอนาคต” ส่วน Hologram Cyan #2EE6FF เป็นสีของ “ข้อมูลและวิทยาศาสตร์” ใช้กับเส้นเชื่อมในกราฟและสถานะข้อมูล
ขั้นที่ 6 กำหนดกติกาการใช้สี 
(2.1 ต่อ) ใช้สัดส่วน 70–20–10 ต่อหน้าจอ คือพื้นดำและสีกระดาษ 70% ผิวการ์ดและเส้นตาราง 20% และสีแบรนด์ไม่เกิน 10% ในหนึ่ง section ไม่ควรมีสีแบรนด์เด่นเกินสองสี เพื่อรักษาความนิ่งแบบแกลเลอรี gradient มีตัวเดียวชื่อ Time Warp คือ linear-gradient(135deg, #FF5A1F, #8C6BFF) สื่อการเดินทางจากอดีตสู่อนาคต ใช้เฉพาะ hero และฉากเปลี่ยนยุค แสงเรืองของโหนดที่ถูกเลือกใช้ 0 0 24px rgba(215, 255, 58, 0.35) ในกราฟความรู้ให้แยกหกหมวดด้วยทั้งสีและรูปทรง เพื่อให้ผู้ที่มองเห็นสีบกพร่องแยกได้ วิทยาศาสตร์ใช้ Cyan #2EE6FF ทรงวงกลม ประวัติศาสตร์ใช้ Ember #FF5A1F ทรงหกเหลี่ยม เทคโนโลยีใช้ Violet #8C6BFF ทรงสี่เหลี่ยม วัฒนธรรมและภูมิปัญญาใช้ Amber #FFC233 ทรงสามเหลี่ยม ธรรมชาติและชีวิตใช้ Bio Green #34E89E ทรงข้าวหลามตัด และศิลปะและการออกแบบใช้ Coral #FF5FA2 ทรงวงแหวน สงวน Lime ไว้ใช้กับ “สิ่งที่ผู้ใช้กำลังเลือก” เท่านั้น สีสถานะใช้ Bio Green เมื่อสำเร็จ Amber เมื่อเตือน และ Alert Red #FF3B4E เมื่อเกิดข้อผิดพลาด ทุกสีที่ใช้เป็นตัวอักษรผ่านเกณฑ์ WCAG AA บนพื้น Void Black และ Lab Graphite เช่น Archive Paper ได้ราว 16.8:1 Lime ราว 17:1 และ Violet ราว 5.3:1 ในโหมดสว่างข้อความรองเปลี่ยนเป็น #55556A และห้ามใช้สีแบรนด์เป็นตัวอักษรขนาดเล็กบนพื้นกระดาษ ให้ใช้เป็นแถบไฮไลต์ใต้ตัวอักษรสีดำแทน
ขั้นที่ 7 วางระบบตัวอักษร เลย์เอาต์ และรูปทรง
 (2.2 Design Language) ใช้ฟอนต์สามตระกูลจาก TH Sarabun Fonts ที่รองรับภาษาไทย หัวเรื่องใช้ Chakra Petch น้ำหนัก 600–700 เพราะรูปทรงเหลี่ยมให้ความรู้สึก sci-fi ชัดเจน เนื้อหาใช้ IBM Plex Sans Thai น้ำหนัก 400–500 ซึ่งให้อารมณ์แบบเอกสารวิทยาศาสตร์และอ่านสบาย รหัส ตัวเลข พิกัด และป้ายข้อมูลภาษาอังกฤษใช้ IBM Plex Mono หัวเรื่องใหญ่สุดตั้งเป็น clamp(3rem, 8vw, 7.5rem) ให้ขนาดปรับตามจอ เนื้อหาขนาด 17–18px ข้อความไทยตั้ง line-height 1.7 ไม่ใส่ letter-spacing กับภาษาไทย และใส่ lang="th" ที่แท็ก html เลย์เอาต์ใช้กริด 12 คอลัมน์บนเดสก์ท็อป 8 คอลัมน์บนแท็บเล็ต และ 4 คอลัมน์บนมือถือ กว้างสุด 1440px ระยะห่างใช้สเกลฐาน 8 (4, 8, 16, 24, 32, 48, 64, 96, 128px) และเว้นพื้นที่ว่างกว้างแบบ white cube ทุกองค์ประกอบใช้มุมฉาก ยกเว้นการ์ดที่ตัดมุม 45° ขนาด 12px ที่มุมบนซ้ายและล่างขวาด้วย clip-path ให้ดูเหมือนพาเนล HUD ปุ่มหลักเป็นพื้น Lime ตัวอักษรดำแบบ mono ตัวพิมพ์ใหญ่ เมื่อ hover ปุ่มจะขยับพร้อมเงาแข็ง 4px 4px 0 #FF5A1F องค์ประกอบเอกลักษณ์ที่ต้องมีทุกหน้าคือ Specimen Label หรือป้ายวัตถุแบบพิพิธภัณฑ์ ใช้ฟอนต์ mono ขนาด 12–13px บอกรหัสความรู้ในรูปแบบ รหัสแบรนด์–ปี–หมวด–ลำดับ (เช่น GRM-1872-SCI-014) พร้อมชื่อเรื่อง ยุคสมัย หมวด และแหล่งอ้างอิง เมนูหลักตั้งชื่อเหมือนห้องจัดแสดง เช่น HALL 01 Exhibitions และ HALL 02 Knowledge Graph
ขั้นที่ 8 สร้างแพตเทิร์นเอกลักษณ์ 
(2.2 Pattern) แพตเทิร์นทั้งห้าแบบมาจากสองโลกเดียวกับระบบสี คือโบราณคดีกับวิทยาศาสตร์ แบบแรกคือ Specimen Grid เป็นตารางกระดาษกราฟช่องละ 48px ใช้เส้นสี Grid Line ทึบราว 40% มีเครื่องหมาย + ทุกจุดตัดที่สี่ และมีพิกัดเล็ก ๆ อย่าง A1, B2 ตามขอบ ใช้เป็นพื้นหลังทั่วเว็บ แบบที่สองคือ Node Constellation เป็นจุดและเส้นบางต่อกันเหมือนกลุ่มดาว ซึ่งก็คือกราฟความรู้ฉบับย่อ ใช้ใน hero และขยับตามเมาส์ช้า ๆ แบบที่สามคือ Time Rings เป็นวงกลมซ้อนที่ดูได้ทั้งเป็นวงปีต้นไม้และจอเรดาร์ ใช้เป็นตัวโหลดแบบกวาดเรดาร์และตัวแบ่ง section แบบที่สี่คือ Glitch Strata เป็นแถบแนวนอนคล้ายชั้นหินที่เหลื่อมกันแบบกลิตช์ ใช้ตอนเปลี่ยนยุคหรือเปลี่ยนบท แบบที่ห้าคือ Booming Burst เป็นเส้นรัศมีที่ระเบิดออกจากจุดกลาง ใช้เป็นลายเซ็นของ Data Booming โดยเฉพาะ ภาพเก่าและภาพจดหมายเหตุให้แปลงเป็นฮาล์ฟโทนสองสี (Void Black คู่ Lime หรือ Ember คู่ Archive Paper) แล้ววางเลเยอร์ scanline ทึบ 3% ทับ จะได้ภาพแบบโปสเตอร์ modern art ที่จำได้ทันที แพตเทิร์นทั้งหมดควรทำเป็น SVG หรือ CSS เพื่อให้เบาและเปลี่ยนสีตามโทเคนได้ ข้อความบนหน้าเว็บก็ควรมีน้ำเสียงเดียวกับแบรนด์ด้วย เช่น หน้าโหลดเขียนว่า “กำลังขุดค้นข้อมูล…” หน้า 404 เขียนว่า “ชิ้นส่วนนี้ยังไม่ถูกค้นพบ” และปุ่มหลักเขียนว่า “เริ่มขุดค้น”
ขั้นที่ 9 กำหนดการเคลื่อนไหว (2.2 Motion)
 หลักของแบรนด์คือ Scan → Decode → Connect เนื้อหาปรากฏขึ้นตามเส้นสแกนที่กวาดผ่าน หัวเรื่องสลับตัวอักษรแบบถอดรหัสราว 600ms ก่อนนิ่ง และเส้นเชื่อมค่อย ๆ ลากต่อกัน ระยะเวลามาตรฐานคือ 150ms สำหรับ micro-interaction 300ms สำหรับ UI ทั่วไป และ 600–1000ms สำหรับฉากเล่าเรื่อง ใช้ easing cubic-bezier(0.16, 1, 0.3, 1) เป็นหลัก ถ้าผู้ใช้ตั้งค่า prefers-reduced-motion ไว้ ต้องปิดกลิตช์และการสลับตัวอักษรให้เหลือแค่ fade และไม่ว่ากรณีใดห้ามมีแสงกะพริบเกินสามครั้งต่อวินาทีตามเกณฑ์ WCAG
ขั้นที่ 10 ระบุสเปกกราฟความรู้ทั้งสองแบบ Data Booming เริ่มจากโหนดหัวข้อเดียวกลางจอ เมื่อคลิก โหนดจะระเบิดเป็นโหนดลูก 6–12 โหนดเรียงเป็นวงรัศมี แต่ละโหนดโผล่ห่างกัน 40ms เส้นเชื่อมลากออกจากจุดกลาง วงแหวน Lime เรืองแสงหนึ่งจังหวะ และตัวนับจำนวนความเชื่อมโยงวิ่งขึ้น ผู้ใช้กดโหนดลูกเพื่อระเบิดชั้นถัดไปได้สูงสุดสามชั้น จากนั้นเว็บพาไปต่อที่ Interactive Graph ส่วน Interactive Graph ใช้เลย์เอาต์แบบ force-directed ขนาดโหนด 8–32px ตามจำนวนการเชื่อมโยง เส้นปกติหนา 1px ทึบ 30% เส้นทางที่กำลังสำรวจเปลี่ยนเป็น Lime เมื่อ hover จะแสดง Specimen Label มีตัวกรองตามหมวด แถบเลื่อนเวลาจากอดีตถึงปัจจุบัน ช่องค้นหา และมินิแมป บนมือถือต้องมีมุมมองแบบรายการเป็นทางเลือก และต้องเลื่อนผ่านโหนดด้วยคีย์บอร์ดได้ ข้อมูลแต่ละโหนดควรมีฟิลด์ id, title_th, title_en, category, era, year, summary, everyday_takeaway และ sources ส่วนเส้นเชื่อมมี source, target และ relation เช่น influenced (มีอิทธิพลต่อ) derived_from (พัฒนามาจาก) และ used_in (นำไปใช้ใน) แต่ละประเภทใช้เส้นต่างกัน คือเส้นทึบ เส้นประ และเส้นจุด
ขั้นที่ 11 ส่งต่อให้ Google Antigravity สร้างเว็บ บันทึก brief นี้เป็นไฟล์ Markdown แล้วเพิ่มเป็น Workspace Rule ผ่านแผง Customizations ระบบจะเก็บไว้ในโฟลเดอร์ .agent/rules/ และ agent จะอ่านเป็นกติกาก่อนลงมือทุกครั้ง Medium (ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชัน) จากนั้นสั่งงานทีละรอบแทนการสั่งทั้งเว็บครั้งเดียว รอบแรกทำ design tokens และหน้า Style Guide รอบสองทำคอมโพเนนต์และแพตเทิร์น รอบสามทำหน้า Home, Exhibitions, Data Booming, Knowledge Graph, Everyday Lab และ About รอบสุดท้ายจึงทำกราฟความรู้ ทุกรอบให้ตรวจ Implementation Plan และภาพหน้าจอที่ agent ส่งกลับมาเป็น Artifacts ก่อนอนุมัติ DEV คำสั่งรอบแรกที่คัดลอกไปใช้ได้เลยคือ “อ่าน brief ใน .agent/rules แล้วสร้างโปรเจกต์ Next.js + TypeScript + Tailwind CSS สำหรับ GRURU MUSEUM แปลงสีทั้งหมดเป็น CSS variables ชื่อ --gr-void, --gr-graphite, --gr-grid, --gr-fog, --gr-paper, --gr-lime, --gr-ember, --gr-violet, --gr-cyan พร้อมสีหมวดและสีสถานะ ตั้งค่าฟอนต์ Chakra Petch, IBM Plex Sans Thai และ IBM Plex Mono ผ่าน next/font สร้างกริด 12/8/4 คอลัมน์ สเกลระยะห่างฐาน 8 และ motion tokens ตาม brief แล้วทำหน้า /style-guide ที่แสดงสี ฟอนต์ ปุ่ม การ์ดตัดมุม Specimen Label และพื้นหลัง Specimen Grid จากนั้นเปิดตรวจในเบราว์เซอร์ว่าความคมชัดสีผ่าน WCAG AA แล้วส่งภาพหน้าจอกลับมา” เมื่อหน้า Style Guide ผ่านแล้ว รอบกราฟความรู้ให้สั่งใช้ D3.js (d3-force) วาดบน Canvas พร้อมไฟล์ JSON ตัวอย่างราว 50 โหนด เพื่อทดสอบความลื่นก่อนใส่ข้อมูลจริง
